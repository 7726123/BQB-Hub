# ADR-0002：大陆访问限制设计为布尔开关

- 状态：已采纳后放开（现 `regionBlock: false`）
- 日期：2026-08

## 背景

社区服务器部署在中国大陆云主机，需求是**可随时限制大陆访客**，
且未来测试后要容易开放。候选方案：GeoIP 库判断、IP 段黑名单、防线前加 CDN 国家码。

## 决策

1. **实现**：`geoip-lite` 查 `country === 'CN'` 即拦截，请求一律 403
   `{error:'当前地区暂不可用'}`。
2. **开关**：`server/config.json` 中 `regionBlock` 布尔值，启动时读入；
   改配置 + 重启进程即生效，不触碰任何业务代码。默认 `false`。
3. **安全**：不信任 `X-Forwarded-For`（可伪造），一律取 socket 直连地址；
   127.0.0.1/::1 本机放行（便于服务器自测）。

## 后果

- 正面：开放/关闭只需改一个布尔值，符合「后续测试完会开放，最好就只是一个 false/true」。
  部署链路不变；拦截对 App 端表现为普通 HTTP 错误，无需客户端改动。
- 负面：geoip-lite 数据库随 npm 安装体积变大；IP 归属判断有 99% 级准确率但非 100%；
  仅拦截大陆 IP，不覆盖其他地区策略（当前无需）。
- 当前状态：**已放开**（false）。验证拦截时必须从大陆出口 IP 测试——
  服务器本机 127.0.0.1 永远放行，私网/服务器所在地 IP 不判 CN。
